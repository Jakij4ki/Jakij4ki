## About

I'm **Dzaky Rezandi**, an **Informatics Engineering student at Brawijaya University** interested in building reliable, practical solutions with data.

My current direction sits at the intersection of **Data Science, Machine Learning, and Data Engineering**. I like the part of a project where raw data has to be understood, cleaned, structured, and turned into something that can actually be evaluated or used.

**Areas I work with:**

- Data analysis, preprocessing, and feature engineering
- Machine learning for classification, prediction, and segmentation
- NLP, text representation, and transformer-based models
- Data pipelines, reproducible workflows, and ML deployment

> **From raw data → structured information → useful models.**

## Selected Projects

### [Diabetes Health Indicators Prediction](https://github.com/Jakij4ki/Diabetes-Health-Indicators-Prediction)
**Classification · Healthcare Analytics · XGBoost**

Predictive modeling workflow using the CDC BRFSS 2015 dataset, covering EDA, preprocessing, model comparison, and evaluation with Logistic Regression, Random Forest, and XGBoost.

### [Yelp Sentiment Analysis](https://github.com/Jakij4ki/yelp-sentiment-analysis)
**NLP · Text Classification · Transformers**

Comparative sentiment analysis using SVM with TF-IDF, Word2Vec, GloVe, and BERT-based approaches to examine different text representations for restaurant reviews.

### [Airline Customer Analysis](https://github.com/Jakij4ki/Analisis-Sentimen-dan-Segmentasi-Pelanggan-Maskapai)
**Customer Segmentation · Prediction · Unsupervised Learning**

Customer analytics combining K-Means and GMM for segmentation with Random Forest and XGBoost for satisfaction prediction.

### [Planetify](https://github.com/Jakij4ki/Planetify)
**Three.js · WebGL · Interactive Visualization**

Interactive 3D Solar System experience featuring animated orbits, raycasting interaction, camera controls, information panels, and planet comparison.
