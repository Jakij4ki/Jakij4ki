## 🚀 Featured Projects

### 🩺 [Diabetes Health Indicators Prediction](https://github.com/Jakij4ki/Diabetes-Health-Indicators-Prediction)

Machine learning project for **diabetes risk prediction** using the CDC BRFSS 2015 dataset. The workflow covers data understanding, EDA, preprocessing, model comparison, and evaluation across **Logistic Regression, Random Forest, and XGBoost**, with XGBoost selected as the final model.

`Python` `Pandas` `Scikit-learn` `XGBoost` `EDA` `Healthcare Analytics`

### 💬 [Yelp Sentiment Analysis](https://github.com/Jakij4ki/yelp-sentiment-analysis)

Comparative study of **classical NLP and transformer-based approaches** for restaurant review sentiment analysis. Experiments include SVM with TF-IDF, Word2Vec, GloVe, and BERT variants to study how different text representations affect sentiment classification.

`Python` `NLP` `SVM` `Word2Vec` `GloVe` `BERT`

### ✈️ [Airline Customer Analysis](https://github.com/Jakij4ki/Analisis-Sentimen-dan-Segmentasi-Pelanggan-Maskapai)

Customer analytics project combining **unsupervised segmentation** and **supervised satisfaction prediction**. K-Means and GMM are used for customer segmentation, while Random Forest and XGBoost are used to predict customer satisfaction.

`Python` `K-Means` `GMM` `Random Forest` `XGBoost`

### 🌍 [Planetify](https://github.com/Jakij4ki/Planetify)

Interactive **3D Solar System visualization** built with Three.js, featuring animated planetary orbits and rotation, raycasting-based interaction, camera zoom, planet information panels, and a planet comparison mode.

`JavaScript` `Three.js` `WebGL` `3D Visualization`
